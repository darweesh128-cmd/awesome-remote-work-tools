# Contributing Guidelines

Thank you for your interest in contributing to this list. Please ensure your pull request adheres to the following guidelines:

- Search previous suggestions before making a new one to avoid duplicates.
- Make an individual pull request for each suggestion.
- Use the following format: `[Tool Name](link) - Description.`
- Link to the official website or GitHub repository.
- Descriptions must be concise, objective, and clearly state the tool's primary function.
- Ensure your text editor is set to remove trailing whitespace.
